# 말도깨비 미로

끝말잇기 공격 단어 퍼즐 게임. 말도깨비(컴퓨터)가 내는 단어를 받아, 보기 중에서 공격 단어만 골라 끝까지 몰아붙이면 탈출합니다. 한 번이라도 길을 잘못 들면 게임은 계속되지만 결국 말도깨비가 이깁니다.

## 실행

**`index.html`을 더블클릭**하면 기본 브라우저(크롬·엣지 등)에서 바로 열립니다. 설치할 것은 없습니다.

- 인터넷이 없어도 됩니다. 글꼴만 기본 글꼴로 바뀝니다.
- 전시용이라 통과 기록은 남기지 않습니다. 아이템 수량·관리자 암호·고른 사전만 그 브라우저에 저장됩니다.

## 규칙

- 끄투룰: 고른 사전의 단어를 모두 허용합니다(동사·형용사 제외 모든 품사).
  - **끄투3 표준 사전**: 표준국어대사전에 있는 동사·형용사 제외 모든 품사의 단어 기반 (추천)
  - **끄투3 복합 사전**: 우리말샘에 있는 동사·형용사 제외 모든 품사의 단어 기반
- 두 글자 이상, 두음 법칙 적용, 한 판에서 같은 단어는 한 번만 씁니다.
- 컴퓨터는 항상 최적의 수를 둡니다. 이길 수 있으면 가장 빨리 이기고, 질 수밖에 없으면 가장 오래 버팁니다.
- 컴퓨터의 제시어는 루트 또는 패배 음절로 시작해 승리 음절로 끝나는 단어입니다. 그런 단어가 없는 글자는 글자 하나만 제시합니다.

화면은 아래에서 위로 올라가는 미로 지도입니다. 갈림길마다 길 끝에 단어 팻말이 붙고, 길을 고르면 등불을 든 캐릭터가 그 길로 걸어갑니다.
지나온 길 바닥에는 내 단어와 말도깨비가 받아친 단어가 적히고, 고르지 않은 길은 막힙니다. 말도깨비가 막히면 출구, 내가 막히면 막다른 길입니다.

## 모드

- **튜토리얼**: 한방 단어(사 → 사기꾼), 몰아붙이기
- **스테이지**: 사전마다 10단계. 모든 단계가 처음부터 열려 있어 아무 단계나 고를 수 있습니다. 보기는 매번 같아서 미로처럼 길을 외울 수 있습니다.
- **랜덤 대결**: 5단계 난이도. 매번 실시간으로 새 미로를 만듭니다(무작위 시작 글자·제시어·보기 시드, 수마다 엔진이 즉석 계산). 보기에 없는 단어를 **직접 입력**할 수도 있습니다(사전에 있는 단어만, 루트 글자로 이어지는 단어는 불가).
- 학교 전시용으로 성·범죄·욕설 관련 단어는 화면(제시어·보기·말도깨비의 단어)에 되도록 쓰지 않습니다. 규칙상 허용되는 단어라 승패 계산에는 그대로 반영됩니다.
- 쉬운 단계일수록 오답이 금방 끝나는 단어로 나오고(틀려도 길게 헤매지 않게), 초중반에는 ‘돌아가서 이기는 정답’이 함께 나오는 차례가 섞여 있습니다.

## 아이템 (축제 전시용)

모든 스테이지와 랜덤 대결이 함께 쓰는 수량입니다. 한 차례에 종류마다 한 번씩 쓸 수 있어요.

- **형세 판단**: 둘 다 최선을 다하면 몇 수 후 이기는지/지는지
- **수 읽기**: 보기마다 말도깨비가 무엇으로 받아칠지
- **최선의 수**: 보기 중 최선의 수 표시
- **전 턴으로 돌아가기**: 내 단어와 말도깨비의 대답을 취소하고 바로 전 내 차례로 (막혀서 졌을 때는 게임 오버 화면 전에 쓸지 먼저 물어봄)

### 관리자: 아이템 넣기

1. 게임 화면 아이템 줄 오른쪽의 **아이템 추가**를 누릅니다.
2. 처음 한 번은 **관리자 암호를 정하는 창**이 뜹니다. 관람객이 보지 않을 때 미리 정해 두세요. (암호는 원문이 아닌 해시로, 그 컴퓨터의 그 브라우저에만 저장됩니다.)
3. 그다음부터는 암호를 넣고, 아이템과 개수를 골라 **추가**합니다. 개수 앞에 -를 붙이면 뺍니다(예: -2, 0개 밑으로는 안 내려감).
4. 암호를 바꾸려면 같은 창의 ‘관리자 암호 바꾸기’. 잊어버렸다면 같은 브라우저로 `tools/reset_admin.html`을 열어 지운 뒤 다시 정하세요.

## 승패 분석

`js/engine.js`는 끝말잇기 엔진(끄글, github.com/singrum/ggeugle)의 분류 방식과 같습니다.
받은 글자를 승리·패배·루트 음절로 나누고, 서로 짝지어 주고받을 수 있는 순환 단어(돌림 단어 짝, 두 글자 순환)를 지운 뒤 다시 채우기를 반복합니다.
한 판 안에서 쓴 단어는 그래프에서 빼고 매 수마다 다시 계산하므로, 단어 재사용 금지까지 반영됩니다.
예: 표준 사전에서 ‘탕’은 11수 승리, ‘솥’은 10수 패배(솥뚜껑), ‘껑’은 9수 승리(돌림 단어 껑껑).

## 데이터 다시 만들기 (개발용)

필요한 것: Python 3, Node.js

```
python tools/prep_defs.py <표준국어대사전 XML 폴더>     # tools/raw/stdict_defs.jsonl
python tools/prep_opendict.py <임시 폴더>               # tools/raw/opendict_defs.jsonl (우리말샘 약 2GB를 받아 읽고 지움)
python tools/build_data.py --fetch                       # data/meta.js, graph_*.js, words_*.js
node tools/make_stages.js                                # data/stages_std.js, stages_ext.js
```
